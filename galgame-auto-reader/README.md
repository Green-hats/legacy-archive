# Galgame Auto Reader / 视觉小说自动阅读工具

一个 Windows 桌面小工具，用于监听剪贴板中的视觉小说文本，根据文本长度估算阅读时间，并在等待结束后自动点击当前鼠标位置。适合配合文本提取工具使用，减少长对白场景中的重复按键或鼠标点击。

## 功能概览

- **剪贴板监听**：检测新文本并加入处理队列，避免连续文本丢失。
- **自适应等待**：根据字数和阅读速度计算等待时间，并支持最短/最长时间限制。
- **自动点击**：支持左键/右键点击，可选择普通点击或 Win32 直接点击模式。
- **热键控制**：默认 `F8` 开始、`F9` 停止，支持在界面中自定义。
- **日志记录**：可选保存运行日志，便于排查点击或热键问题。
- **轻量界面**：基于 Tkinter 实现，无额外前端框架。

## 使用场景

- 视觉小说、Galgame、文字冒险游戏的自动阅读。
- 搭配文本提取工具，将游戏文本复制到剪贴板后自动等待并点击。
- 长篇对白场景中减少手动点击或按键操作。

## 环境要求

- Windows 10/11
- Python 3.8+
- 依赖见 `requirements.txt`

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

首次启动时，如果当前进程不是管理员权限，程序会尝试申请管理员权限重新启动。部分全屏或 DirectX 游戏可能需要管理员权限才能稳定发送点击事件。

## 参数说明

| 参数 | 说明 |
|------|------|
| 阅读速度 | 用于计算等待时间，公式为 `文本字数 / 字速` |
| 最短/最长时间 | 限制自动等待时间的上下限 |
| 鼠标按钮 | 选择左键或右键 |
| 使用直接点击 | 通过 Win32 API 发送按下/抬起事件 |
| 保存日志 | 在 `galgame_reader_logs/` 中写入运行日志 |

## 等待时间计算

```text
原始等待 = 文本长度 / 阅读速度
最终等待 = clamp(最短时间, 原始等待, 最长时间)
```

等待过程按短时间片执行，因此停止热键可以中断尚未完成的点击任务。

## 常见问题

| 问题 | 处理方式 |
|------|----------|
| 没有自动点击 | 确认程序已开始运行，并且剪贴板出现了新文本 |
| 游戏内点击无效 | 尝试启用“使用直接点击”，或以管理员权限运行 |
| 热键无效 | 检查是否被其他软件占用，尝试改为组合键 |
| 等待时间过长 | 提高阅读速度或降低最长等待时间 |
